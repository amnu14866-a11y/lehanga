# Royal Lehenga 🛍️

A responsive women's lehenga e-commerce website built using:

- HTML5
- CSS3
- JavaScript

## Features

- Responsive design
- Product listing
- Product search
- Category filtering
- Shopping cart
- Add/remove products
- Cart total calculation
- Contact form
- Mobile-friendly layout

## How to Run

1. Download or clone this repository.

2. Open the project folder.

3. Open `index.html` in your browser.

No server is required.
